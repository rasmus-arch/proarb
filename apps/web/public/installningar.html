Utseende på offert

Påminnelser

Skickar en påminnelse om obesvarade offerter. Kräver att en e-postleverantör kopplas in (inte gjort ännu) — det här styr bara om/när det ska ske en gång det finns på plats.

Kundportal ("Mina sidor")

Av som standard — lagersaldot stämmer bara om ni gjort en fullständig inventering. Slå på när ni är klara med den.

Ordersedel

Öppnar utskriftsdialogen i webbläsaren direkt vid nyskapande. Kräver ändå att någon klickar "Skriv ut" om inte datorn är inställd för tyst utskrift (t.ex. Chrome i kioskläge med en fast skrivare) — det är en engångsinställning på just den datorn, inget appen styr.

Numrering

Offert- och ordernummer går i följd (t.ex. OFF-0001, ORD-0001). Ändra bara vid t.ex. byte från ett annat system — värdet här är numret som används NÄSTA gång.

E-post (SMTP)

Krävs för att "Maila offert till kund" och mail vid "Redo för utlämning" faktiskt ska skickas. Fyll i när ni har en SMTP-leverantör — fram tills dess sparas bara inställningarna, inget mejl skickas.

Fortnox

Krävs för att fakturor faktiskt ska skapas/skickas i Fortnox (när en order blir Utlämnad/Fakturerad, samt vid retur). Client ID/Secret skapas under Mina sidor → Integrationer → API i Fortnox som en egen "app" — ange adressen nedan som dess redirect URI innan du ansluter.

Buggrapporter (GitHub)

Krävs för att "Rapportera problem" faktiskt ska skapa ett GitHub-ärende. Skapa en personal access token med rättighet att skapa issues i repot (GitHub → Settings → Developer settings → Personal access tokens). Fram tills det är ifyllt sparas rapporten bara internt i ProArb.

Användare

Vem som kan logga in och vilken roll de har. ADMIN har full åtkomst; SALES, WAREHOUSE och POS är begränsade till sina respektive delar (t.ex. krävs WAREHOUSE eller ADMIN för att ändra lagersaldo).
